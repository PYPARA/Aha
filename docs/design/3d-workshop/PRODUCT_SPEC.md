状态：**首版源码与 macOS arm64 本机验收完成**。更新日期：2026-10-23。本文描述当前实现范围；操作说明见 [3D 工坊](../../guides/MODEL3D_WORKSHOP.md)，长期约束与回归入口见 [维护文档](../../development/MODEL3D_WORKSHOP.md)。早期 2026-10-20 示意稿已归档到本机忽略目录，不能用示意模型或演示统计代替真实结果。

## 产品目标与范围

在最左侧导航新增「3D 工坊」，默认位于精灵动画后、资源中心前。以单个静态游戏道具工程完成“描述需求 → AI 建模 → 预览与修改 → 采用版本 → 保存和导出”，支持多个命名部件。

首版同时提供两条真实建模路线：

| 路线            | AI 提交                                                     | 执行                                                                                 | 结果与衔接                                                   |
| --------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Three.js 程序化 | `buildModel({ THREE, params }) → THREE.Group`、参数定义与值 | 专用 Electron 沙箱进程中的 Worker，固定 Three.js 0.186.1，离线运行                   | 校验网格/PBR 数据后生成真实 GLB，可作为 Blender 父版本       |
| Blender MCP     | 命名部件与 PBR 的 Python 建模代码                           | Aha 管理的专用可见 Blender GUI，固定 mcp-for-blender 2.2.2 与配套插件，MCP SDK stdio | 固定发布脚本保存 `.blend` 检查点和 GLB，统一用 Three.js 查看 |

两条路线复用已有聊天模型、模型选择、附件、历史和 Agent Gateway，不增加独立模型账号/API Key。普通自然语言迭代直接提交新候选；采用、归档与导出由工作台明确操作。生成质量取决于当前会话模型和要求，不承诺模型自动达到所有游戏的制作标准。

首版支持基础 PBR 参数、本地贴图、GLB/完整 glTF 导入、通用 GLB 与 Godot 导出，以及资源中心来源与持久化入库。角色绑定、动画、AI 贴图生成、云端 3D 生成、Unity/Unreal 专属导出、LOD 与碰撞体继续留在后续范围。

## 工作台与数据

- 工程首页：新建、搜索、打开、归档过滤；模型导入位于工程内，导入产生候选。
- 工程工作台：左侧对象/版本，中央模型，右侧属性/AI 助手，底部任务状态；生成/检查/导出切换工具，中央预览保留。中等窗口将版本选择移到预览工具条，窄窗口使用现有 Sheet 工具面板。
- 预览支持旋转、平移、缩放、视角重置、材质/实体/线框、网格、包围盒、部件反馈。几何、顶点、尺寸、材质、贴图与文件大小读取实际产物。显示模式不改写模型。
- 参数、材质修改和 AI 修改都产生新候选。预览版本与采用版本分开，导出只使用采用版本。新一轮 AI 读取当前预览、对象、源码、参数和检查结果；可采用历史版本回退。
- `Documents/Aha/Models3D/<projectId>/` 的文件是数据真相：工程清单、不可变版本、任务输入、贴图、源码、GLB、可选 `.blend`、依赖版本、哈希和报告。没有新增数据库迁移或改写精灵格式。
- 每工程串行提交、修订号与稳定请求回执；输入先落盘，结果验证成功后原子发布。重启恢复已提交结果，不自动重放不明 Blender 操作。会话删除仅解除关联，模型和源文件保留。

## 执行与资产边界

Three.js 代码没有应用 bridge、Node、文件或网络能力；宿主验证 Worker 数据后才进入可信解析、贴图和 GLTFExporter。源码最多 1 MiB，执行 30 秒；模型最多 100 MiB、100 万三角面、5000 个部件。错误/超限终止隔离执行，保留源码与错误。展示相机、灯光、网格不进入资产。

Blender 运行目录与用户配置由 Aha 私有管理。全局一个 Blender 任务，每次 Python 调用 120 秒。专用进程是工程隔离，不是 OS 级 Python 沙箱；启用上游安全模式，关闭遥测及第三方生成入口。任务仅终止 Aha 启动的进程句柄，保留上次检查点。正式保存路径由 Aha 固定发布脚本指定。Three.js 到 Blender 为派生版本，Blender 编辑不会还原成参数化源码。

默认米制、Y 轴向上、生成模型底部中心轴心，建议 5000 三角面和 2K 贴图。预算用于提示，硬性容量另行限制。本地贴图复制并规范进工程，GLB 内嵌 PNG，处理 sRGB/线性和粗糙度 G/金属度 B 通道。缺 UV、法线和不支持的 Blender 节点明确提示或阻断。

导入 glTF 校验完整本地依赖、相对路径、缺失文件和总容量，不下载远程 URL，不执行外部源码。导出重新校验采用版本哈希和 glTF 完整性，提供 `model.glb`、缩略图、清单、报告及可选源码/`.blend`，目标采用新版本目录和原子提交。Godot 预设直接使用标准 GLB，无 `.blend` 导入依赖；清单明确 LOD/碰撞体未提供。

资源中心新增 3D 类型与工程/版本来源，复用目标目录、持久化复制回执和失败重试。列表只显示图标或缩略图，详情按需加载同一查看器；失败重试不触发 AI。
