## 放置与维护

- `guides/`：面向使用者的当前行为与操作说明，跟随功能更新。
- `development/`：仍有效的数据约束、开发约定和可复用技术说明，不逐次记录实现流水账。
- `design/<主题>/`：需要随源码保留的实施中方案；标明状态，区分方案示意与实际实现，避免把尚未验证的行为写成已交付。
- `.tmp/<主题>/`（仓库根目录，已忽略）：过程日志、截图、录屏、审查证据、完成后的历史方案和测试产物。必要结论先收敛到长期文档；测试应直接把产物写到这里。

2026-10-20 整理前的文档快照与多轮创作工作台设计资料保存在本机 `.tmp/docs-cleanup-20261020/`，用于回溯，不是运行或开发依赖。该目录不会随 Git 分发；新环境以这里列出的长期文档和源码为准。
