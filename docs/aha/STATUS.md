## 实现

- 固定内置 ID：`synara-default`、`aha-elation`、`furina-chanson`。升级初始保存“当前自定义外观”，不会自动换肤。
- `packages/contracts/src/ahaSkins.ts` 定义皮肤、调色板、revision、快照、预览、v4 包和桥接口；preload + IPC 只接受 ID/结构化数据，信任校验限主窗口主 frame，导入文件路径仅由原生选择器取得。
- `apps/desktop/src/aha/skin-library.ts` 为独立皮肤库。原定义/调整/活动 ID/有效图标/深浅配色/外观/revision 存于一个原子文件 `aha-skins.json`。应用按序校验 → 原生图标 → 原子保存 → 通知 renderer；保存失败回退图标，失败不更新活动配置。
- 重新应用图标与应用保存走同一串行队列。原生失败、资源失败、revision 冲突和库损坏均保留既有文件/配置。损坏库阻止写入而不会自动清空。
- 导入成功立即入库；取消只结束预览。导入内容按规范化资源/定义去重（包含已有内置原定义与调整）；同名异内容加序号。支持非内置重命名/删除、静态本地图标补充和默认恢复；活动皮肤必须先切走再删除。
- 旧 v1/v2/v3 主题包转换为继承图标的皮肤；每次切换沿用当时实际图标，存储有效图标供重启恢复。v4 包最多六张去重图片、总计 100MB，图标 1024px 静态 PNG，导出包含已应用调整，暂时关闭背景也保留其资源供往返导入。
- 颜色预览进入 useTheme 临时 snapshot，编辑器与共享 Logo 同步看到草稿；编辑颜色不会提前写入已保存外观，取消/离开撤销颜色，字体/模式/材质/代码主题继续全局保存。
- renderer 沿用设置行/选择控件/按钮与现有预览流程。共享 Logo、favicon 随预览变化；原生 Dock/Finder 仅应用后变化。App icon 行无 Synara 选项，点击重新应用已保存皮肤图标。
- 颜色合并只替换深浅 chrome 颜色，保留语言/字体/字号/字重/模式/材质/代码主题；没有改变消息测量与布局。背景层沿用 pointer-events:none。
- 显式 `AHA_HOME` 同时隔离后台数据和 Electron profile，避免开发包冒烟进入用户配置。
