# 资源中心

资源中心是桌面端的独立素材库，入口位于最左侧导航的绘图之后。它不关联会话项目或代码项目。

## 使用

1. 首次使用自动创建系统文稿目录下的 `Aha/Resource`，仍可更换总目录；已有自选目录保持不变。一级子文件夹是资源项目；可以在项目中建立多级目录。已有总目录中的散落文件应先移入项目子文件夹。
2. 在绘图结果、聊天图片、文件附件或可定位的文件链接上右键选择「添加到资源中心」，选择项目／目录。也可以通过图片旁的按钮添加。绘图任务菜单支持收藏全部结果。
3. 可直接导入或拖入本地文件、文件夹；文件夹层级会保留。收藏和导入保存独立文件副本，源记录删除不影响素材。
4. 同名同内容跳过，同名不同内容自动加序号；不同目录中的副本独立管理。符号链接不会导入。
5. 左侧资源树可通过箭头展开／收起，默认展开一级项目；展开文件夹时按需读取直属资源，子文件夹排在前面，超过 100 项可「加载更多」。点击目录名称进入目录并展开其父级；单击文件定位到右侧对应目录、分页并勾选，已在当前目录显示的文件可再次单击取消勾选。定位时清除搜索与筛选，以显示目标资源；双击或 Enter 打开详情。拖动右侧边框可调整宽度并记住设置，边框聚焦后也可通过左右方向键调整。
6. 支持网格／列表、名称搜索、标签和类型筛选、批量移动／改名／删除、标签和备注。单击文件切换勾选，复选框也可多选；键盘空格切换勾选，Enter 打开详情。搜索框下方操作行始终保留，无选择时禁用相关操作，选择变化不会推移网格。批量改名使用前缀＋序号并保留扩展名。
7. 双击文件打开详情弹窗，保留原勾选状态。图片显示大图，右侧提供路径、大小、修改时间、标签、备注、来源、导出和文件夹定位；窄窗口上下排列。标签和备注通过「保存」提交，关闭后未保存编辑丢弃。弹窗不占用页面布局，关闭后保留浏览位置；右键文件只选中目标。
8. 文件可导出，也可加入已有或新建会话的草稿；兼容的图片可加入绘图参考。不会自动发送或启动生成。聊天和绘图沿用各自原有附件限制。
9. 删除通过系统废纸篓完成。操作失败会报错，不回退到永久删除。恢复请在系统文件管理器进行。

## 存储、同步与迁移

- 配置文件：桌面 `STATE_DIR/resource-library.json`，仅保存当前根目录。
- 可迁移元数据：根目录下 `.aha-resources/library.json`，记录库版本、稳定 ID、相对路径、标签、备注及生成来源；必须随整个根目录一起备份。
- 原件：项目目录中的真实文件；缩略图在 `.aha-resources/thumbnails`，可重建。
- 搜索索引：配置文件旁的 `.index.sqlite`，可以删除后重建。不是资源库迁移所必需的内容。
- 文件监听合并变化后扫描；启动、手动刷新及 15 秒周期扫描补偿漏报。目录失联不会被解释为所有素材删除。
- 外部改名／移动优先按文件身份关联，整库迁移保留相对路径标识；唯一内容匹配可以恢复部分移动和删除恢复记录。多个完全相同的文件导致歧义时，不猜测元数据归属。
- 首次默认目录创建失败会显示错误并允许另选目录；已配置目录失联时不会自动切回默认空库。首版同时打开一个本机库。切换库不移动旧目录；不支持云同步、多主机共用同一个库或多人同时编辑。

## 新生成模块如何接入

共享类型与渠道在 `packages/contracts/src/resourceLibrary.ts`。桌面主进程服务位于 `apps/desktop/src/resources`，通过受信任主窗口的 IPC 提供能力。页面不直接访问磁盘。

前端复用 `collectResources()`，传入 `ResourceSource[]`：文件名、可访问的下载 URL 或本机路径，以及可选 `origin`。调用后统一展示项目／目录选择器。

游戏生成可设置 `origin.kind = "game"`，附带 `batchId`、`prompt`、`model` 和 `parameters`。由用户挑选满意结果后主动收藏；不会自动导入整个生成历史。成套资源首版按目录组织，不把资源包作为独立数据类型。

底层 `window.desktopBridge.resourceLibrary.request()` 支持 `snapshot`、`list`、`chooseRoot`、`refresh`、`createDirectory`、`importPaths`、`importBytes`、`cancelImport`、`rename`、`move`、`metadata`、`read`、`export`、`trash`、`reveal`。变更和导入进度通过 `onChanged` / `onProgress` 订阅。

原生路径导入和导出按文件复制，不要求将大文件传入渲染器。通过 IPC 读取原件或通过 URL 收藏限制为 100 MiB；超大文件仍可本地导入、整理和导出。取消批量导入在当前文件复制完成后生效，已完成文件保留，失败项可重试。

## 验证

- `bun run test apps/desktop/src/resources apps/web/src/components/resources/resourceNavigation.test.ts`
- 在 `apps/web` 运行 `bun run test:browser src/components/resources/ResourceCenter.browser.tsx`
- 桌面、Web、contracts 类型检查及桌面／Web 构建。

文件系统测试使用临时目录。废纸篓测试替代系统调用，验证取消与失败不会导致永久删除；不会清理用户的系统废纸篓。

## 右键菜单兼容

聊天图片、生成图片、绘图缩略图／详情和放大预览保留 Electron 原生右键菜单，末尾追加“添加到资源中心”。图片内嵌于链接时，收藏项追加到链接原菜单；文件引用保留引用到聊天、Finder 显示和复制路径等原操作。

原生菜单扩展只查询当前受信任应用页面，按请求 ID 和点击位置关联资源，150 毫秒超时后显示原菜单。取消、新右键、页面离开和渲染进程退出会清理待处理请求。资源地址、来源信息和授权解析回调留在渲染端，展开菜单时不会下载或导入资源。
