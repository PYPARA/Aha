# 资源中心

资源中心用于浏览已有素材、预览、整理，并将素材用于聊天或绘图。它映射已有物理目录，不会自动重命名、移动或重新分类原文件。

## 目录与浏览范围

左侧为“资源库根目录 → 项目 → 子目录”。点击箭头只展开或收起，点击名称进入该目录；查找目录保留祖先路径，不会改变右侧的内容搜索。树节点数字表示包含子目录的文件总数，不随右侧筛选变化。

物理目录默认显示“当前目录”的直接子目录和文件，切换“全部素材”可递归查看该目录的文件。“全部资源”覆盖整个资源库，包括根目录散落文件；“最近修改”在同一文件集合中按修改时间倒序排列。

内容搜索匹配文件名和相对路径，范围由当前浏览位置决定。聚合和搜索结果显示所属路径；“定位目录”会进入父目录、翻到目标所在页，并选中和聚焦该文件。返回、前进和面包屑用于导航，返回时保留相应位置的筛选、排序、分页和滚动上下文。

列表每页最多显示100项，目录与文件共同分页。底部持续显示区间与分页，区分目录数和文件数；正在加载或统计不可用时不会用0冒充已完成扫描。

## 选择、预览与整理

- 内容区单击选择，Cmd/Ctrl 加选，Shift 连续选择，也可使用显式多选和空白区域框选。目录树的激活位置与素材选择互相独立。
- 文件通过空格或双击预览，目录通过双击进入；Escape 关闭预览后恢复原焦点。切换布局和打开详情保留选择，导航、切页或改变筛选/范围会清空选择。
- 详情可查看路径、标签与来源。尚未保存的修改离开前需要确认；保存失败保留草稿。
- 导入、移动和收集需要明确目标目录。资源库根目录也是有效目标；全库视图导入时先选择目标，不按当前结果猜测位置。
- 批量操作先核对对象和影响；部分失败保留失败项，后续只重试失败部分。用于聊天或绘图会确认接收结果，不直接发送消息或提交生成。

## 键盘与窄窗口

目录树支持上下移动焦点、左右展开/收起、Home/End 和 Enter 导航。焦点移动不隐式选中内容区文件；输入框内保留正常文字编辑。

工作区不足以并排显示时，目录和详情改为抽屉或覆盖面板。字号放大后重新计算空间，预览使用公共不透明底板隔离背景。

## 索引与失败恢复

批量生图的结果需要在批次工作台中选择后手动入库。「选用」是批次服务保存的系统状态，与资源标签分开；详情可查看该状态并回到批次、任务和结果。来源筛选可以单独查看批量生图；旧绘图来源的 `batchId` 保持原有含义，不被当成新批量来源。

批次入库按逐项回执恢复，换页和重启不丢失操作；同一结果在同一资源库内重复加入会返回已有文件，不复制第二份。目录或库失效时重新选位置，复制失败不重新生图。详见[批量生图](IMAGE_BATCHES.md)。

扫描未完成、目录不可读或索引提交失败时会显示状态与原因，并保留上次有效索引。失败期间暂停写操作；仍可读取、预览或在 Finder 中定位可用缓存项。成功重扫后恢复写入。

无法读取的目录不会被当成已删除，符号链接不会被跟随。发现页内容与索引版本不一致会重新读取。实现约束与回归入口见[创作功能维护](../development/CREATIVE_WORKBENCHES.md)。
