# 3D 生成

3D 生成在主导航的 3D 工坊之后。它从一张三视图参考出发：AI 用 Three.js 和 SDF（有向距离场）或 Blender 建模，每次构建都和参考剪影比对评分，再根据差异图修改，直到轮廓吻合。每一轮结果都保留为候选版本。

## 参考与蓝图

1. 新建 3D 资产，打开工程。
2. 在「参考与蓝图」中添加参考图：
   - 「上传参考图」：一张纯色背景、从左到右依次排列正视、侧视、背视的图片。
   - 「生成三视图」：用你的绘图渠道生成一张 1536×1024 的三视图。生成前会显示渠道和模型，结果会记录在绘图中，渠道可能计费。
3. 填写资产的真实高度（米），点击「提取蓝图」。Aha 按列切出三个视图，提取剪影，三个视图共用同一个比例。
4. 检查三个剪影，无误后点击「确定」。

侧视图里的物体正面朝左或朝右都可以，评分会自动匹配镜像方向。

## 建模路线与骨架

AI 助手每次构建时自己选择路线，「属性」面板会显示两条路线当前是否可用，版本信息里会标出每一版用的路线。

- **Three.js + SDF**：默认路线，构建只要几秒，适合大多数资产。
- **Blender**：AI 写 Blender Python，可以用 Skin、细分、倒角、布尔、镜像等修改器。
  - 需要先在 3D 工坊里设置好 Blender 运行环境。3D 生成和工坊共用这套环境，同一时间只运行一个 Blender 任务；工坊正在用 Blender 时，3D 生成最多等待 90 秒。
  - 每次构建都会启动一个专用 Blender 窗口，比 Three.js 路线慢。
  - 运行环境没准备好时，AI 的 Blender 构建会被直接拒绝，不消耗授权轮数。
- **骨架**：做角色、生物、树木这类资产时，AI 会先给出骨架（关节位置、父子关系和半径），再沿骨架生成身体，两条路线都支持。骨架随版本保存，导出时一起导出，「绑定动画」用它生成骨骼。
- **部件**：模型由多个部件组成时，每个部件有稳定的 id。用 SDF 融合成一整块的身体，AI 可以把头、尾巴、耳朵等区域分别命名，它们会成为独立的部件，可以有自己的颜色，也可以单独选中、做道具动画或在优化时保留。可以直接要求 AI「把尾巴单独分出来」或「耳朵用另一种颜色」。

## 生成与迭代

- 「属性」里可以填写资产描述和三角面预算。
- 设置「最多轮数」（1–10），点击「开始生成」：
  - Aha 会授权 AI 助手在这么多轮内自行构建，并在「AI 助手」中预填一条消息，由你发送后开始。
  - 只消耗会话模型轮次，不调用生图。
  - 最大偏差区域低于 2%，或分数连续两轮提高不足 1 分时自动停止。
  - 重启后不会自动继续。
- 没有授权时，你每发一条消息，AI 最多构建一次。
- 工程第一次打开「AI 助手」时会新建一个对话：沿用聊天输入框当前的模型，但推理等级自动设为这个模型支持的最高档（GPT-6.1 Sol 为 max），因为读三视图、摆放部件和修正偏差都很依赖推理。每轮会更慢、更费额度；需要时可以在助手的输入框里改低。已有的对话保持原来的设置。
- 迭代过程中可以随时在任务栏或属性面板停止。

每轮 AI 会读取蓝图、上一版的差异图和渲染图，然后只修改有偏差的部分。模型思考一轮通常需要几分钟，构建和评分只要几秒。

## 查看与比对

- 「模型」视图可以拖动旋转、右键拖动或方向键平移、滚轮缩放，R 重置视角。工具栏：
  - 显示（按 1–9 切换）：材质（PBR，带环境反射）、基础色、法线、粗糙度、金属度、环境光遮蔽、UV 棋盘格、线框、纯色。粗糙度、金属度和 AO 显示贴图里存的原始数值，没有对应贴图时显示材质的统一数值。绑定版本还有「蒙皮权重」，选择一根骨骼后用蓝到红的颜色显示它对每个顶点的影响。
  - 参考叠加：已按蓝图评分的版本可以切换到正视、侧视或背视，用和评分相同的对齐方式把蓝图剪影的轮廓叠在模型上。
  - 对比：选择另一个版本，左右并排显示，两边共用一个视角。
  - 动画：绑定版本和道具动画版本可以选择动画片段播放，空格暂停；「静止姿态」回到发布时的姿态。勾选「骨骼」显示骨架。
  - 网格、尺寸（包围盒和三条边的长度）、转台（T 键，自动环绕）。
  - 选择部件：单击模型上的部件选中它并显示外框，按住 Cmd 或 Ctrl（Shift 也可以）单击加选或取消，单击空白处清空。选中的部件和「道具动画」的部件列表是同一组。
- 「比对」视图显示三视图差异图：灰色表示吻合，橙色表示模型多出，蓝色表示模型缺少。同时列出偏差最大的区域和各视图 IoU。
- 版本列表显示每一版的轮次、分数和最大偏差。查看其他版本不会自动采用它。

评分只反映剪影和比例，风格与细节请在模型视图中检查。底部信息栏会提示非流形边等需要处理的问题。

## 优化与烘焙

AI 建出的模型通常面数很高、没有 UV。「优化」工具会从当前查看的版本生成一个游戏可用的新版本：

1. 选择目标面数：主资产 2 万、普通道具 5 千、背景 1.5 千、手机 800，或者自定义（100–200,000）。
2. 选择贴图尺寸（512–4096），以及要做的处理：
   - 修复网格：焊接重复顶点、删除游离的点和边、重算法线。
   - 重新展开 UV 并烘焙贴图：把原模型的颜色、粗糙度、金属度、法线和 AO 烘焙到低模上，输出一张颜色图、一张法线图和一张 AO/粗糙度/金属度合并图。不勾选时保留原有材质和 UV。
   - 颜色来源（勾选烘焙时）：
     - 模型材质：沿用模型原有的颜色。
     - 投影三视图参考：按蓝图对齐把参考图画到模型可见的表面上。被挡住的地方（比如面罩后面、身体被尾巴挡住的部分）不会被错误上色，顶面、底面和投不到的地方保留材质颜色。需要已确认的蓝图，以及按这份蓝图评过分的版本；蓝图重新提取后，要先重新构建一个版本。
   - 材质预设（勾选烘焙时）：可以给每个材质选一种程序材质——木头、拉丝金属、喷漆金属（边缘磨损）、金、石头、布料、皮革、塑料。预设会加上纹理、凹凸和粗糙度变化，然后烘焙进贴图。和投影一起用时，颜色以投影为准，预设提供凹凸、粗糙度和金属度。
   - 平铺贴图（勾选烘焙时）：材质也可以选「平铺贴图」，再选工程里已有的贴图，或点「生成…」用绘图渠道画一张（例如「有明显木纹的旧深色橡木板」）。Aha 会把它处理成无缝贴图，按「每次重复（米）」的真实尺寸铺满这个材质，并从图的明暗推出凹凸和粗糙度，一起烘焙进贴图。生成的贴图会记录在「绘图」中，服务商可能计费；同一工程最多保留 64 张。
   - LOD：再生成 50% 和 25% 两级，共用同一套贴图。
   - 保留独立部件（模型有多个部件时）：低模按原来的部件拆开，部件共用一套 UV 和贴图，方便之后做道具动画。不勾选时合并为一个网格。
   - 碰撞体：包围盒或凸包（最多约 250 面）。
3. 点击「生成优化版本」。

优化在后台 Blender 里运行 Aha 自带的固定脚本，不执行 AI 代码，也不消耗模型轮次，通常 5–10 秒，投影和材质预设各会多几秒；4096 贴图会更慢，可以随时取消。需要本机装有 Blender（在 3D 工坊里设置路径即可，不需要准备 MCP 运行环境）。优化结果是一个新的候选版本，同样会按蓝图评分、渲染和检查，版本信息里显示面数变化、LOD 和碰撞体。AI 助手继续建模时会基于它的原始版本，不会修改优化版本。

## 贴图：局部重绘

「贴图」工具可以修改优化版本里烘焙好的颜色贴图，比如把锁换成骷髅造型、给盾牌加纹章：

1. 选中一个带烘焙贴图的优化版本。视角默认是「在模型上画（自由视角）」：
   - 直接在查看器里的模型上拖动，画出要修改的区域（蓝色）。按住 Option 拖动或选橡皮擦除；右键拖动或在模型旁边拖动旋转视角，滚轮缩放；`[` / `]` 调整笔刷大小，`E` / `B` 切换橡皮和画笔，Cmd+Z 撤销一笔。
   - 把模型转到画过的区域正对你，点击「渲染当前角度」。Aha 按这个方向渲染一张正交图，画面对准画过的区域，遮罩直接取自模型上画的部分；需要时可以「在 2D 中调整」。
   - 也可以选择固定视角（正面、右前、右侧、背面、左侧、左前、顶部），点击「渲染视图并绘制遮罩」，在弹出的画布上涂遮罩。
2. 写下要画成什么，选择遮罩边缘的柔化程度和绘图模型，点击「重绘」。

Aha 会用绘图渠道对这个视图做一次局部重绘（记录在「绘图」中，服务商可能计费），再把遮罩内的结果投影回贴图，生成新版本。只有遮罩内、这个视角能直接看到的表面会改变，其余贴图与原版本完全一致，几何、法线、LOD 和碰撞体也不变；LOD 会同步换上新贴图。绘图模型有时会改动遮罩外的画面，这些改动不会被采用。

- 侧面、顶面等斜着的表面要换到正对它的视角再重绘，否则颜色会被拉长。画在背面、当前角度看不到的部分不会改变；全部看不到时渲染会提示换个角度。
- 自由视角会放大画过的区域，绘图模型能画出更多细节，但最终清晰度受贴图分辨率限制（整个模型共用一张贴图），小区域的结果会比编辑图柔和。
- 遮罩跟着模型走：切换到其他工具再回来，同一版本画过的遮罩还在；重新画之后需要重新渲染。
- 要求写得越局部越好（例如「银色骷髅锁」而不是「整个箱子刷成红色」），遮罩边缘才不会出现明显的色块边界。
- 可以在重绘过的版本上继续重绘。重新建模或重新优化会得到新的贴图，之前的重绘不会带过去。导出时 `asset.json` 的 `repaints` 记录每次重绘的视角和要求。

## 绑定与动画

「绑定动画」工具可以让带骨架的角色和生物动起来：

1. 选中一个版本。优化、重绘、风格化过的版本会沿用来源版本的关节。用于游戏时建议绑定优化版本。
   - 按骨架建模的版本（让 AI 助手为角色、四足动物、尾巴等按骨架建模）已经有关节。
   - 没有关节的版本可以：点「两足模板」或「四足模板」，得到按模型尺寸缩放的一套关节；或点「让 AI 助手放置」，Aha 会在 AI 助手里预填一条消息，发送后 AI 根据正面和侧面渲染图提出关节，不会重新建模。
   - 关节显示在正面和侧面渲染图上，可以直接拖动；也可以在列表里选中一个关节，再在渲染图上用方向键移动（按住 Shift 移动更多）。默认左右对称，移动 `_l` 关节时 `_r` 关节跟着镜像。确认后才能绑定；AI 提出的关节必须由你确认。
   - 绑定后仍可以点「调整关节」重新调整，再生成新的绑定版本。
2. 勾选要生成的动画：待机、行走、奔跑、攻击。
3. 点击「生成绑定版本」。

Aha 在后台 Blender 里按骨架生成骨骼、自动计算蒙皮权重，再加上程序动画，几秒钟就能完成，不执行 AI 代码。骨骼名就是骨架里的关节名。两足和四足按关节名（`thigh_l`、`upperarm_l` 等）识别：躯干前后走向、前肢末端贴近地面的是四足；其他骨架只生成待机摆动。头盔、盾牌、耳朵这类单独的小部件只跟随离它最近的骨骼，不会被手臂带着变形。

- 面板里会显示每段动画的循环预览（由 Blender 渲染）、骨骼数和识别出的类型。工作台的三维查看器仍显示静止模型。
- 绑定版本导出 GLB 或 FBX 时包含骨骼、蒙皮和全部动画；Godot 和 Unity 导入后可以直接播放。glTF 和 FBX 没有循环标记，循环动画需要在引擎里打开循环（`asset.json` 的 `animation.clips` 写明哪些是循环）。Unity 里 FBX 的动画名形如 `<资产名>_Rig|walk`。
- 绑定版本不带 LOD，碰撞体照常导出；OBJ、USDZ、STL 只导出静止模型。
- 可以对绑定版本继续局部重绘，骨骼和动画保留；重新优化或重新建模后需要重新绑定。

### 道具动画

「绑定动画」下方的「道具动画」用来让模型的某几个部件动起来，比如打开宝箱盖、开门、转动风车、拉出抽屉：

1. 在部件列表里勾选要动的部件。可以先输入名称筛选（如 `lid`），再点「选中筛选结果」。至少要留一个部件不动；选中分组时，其中的子部件一起动。
2. 选择动作：
   - 合页盖子：沿选中部件底部的后边、前边、左边或右边转动，向上打开。
   - 合页门：沿左边或右边竖直转动，向前打开。
   - 旋转：绕竖直轴循环旋转。
   - 滑动：向前、向上、向左或向右移出，距离默认取部件在该方向尺寸的 80%。
3. 填写打开角度和时长，点击「生成动画版本」。

盖子、门和滑动生成「打开」「关闭」两段动画，旋转生成一段循环动画。导出 GLB 或 FBX 时包含这些动画，动画作用在名为 `Pivot` 的支点节点上。只有一个网格的版本（比如普通优化版本）不能选部件，要对建模版本做动画，或者优化时勾选「保留独立部件」。

## 风格化

「风格化」工具把当前版本重建成另一种风格，结果是新的候选版本：

| 风格     | 效果                                     | 精细度                    |
| -------- | ---------------------------------------- | ------------------------- |
| 体素     | 实心方块，颜色取自模型表面               | 最长边上的方块数（8–96）  |
| 积木     | 积木块加顶部凸点，颜色归到一套固定调色板 | 最长边上的积木数（6–64）  |
| 低多边形 | 平面着色的多边形，每个面一种颜色         | 目标三角面数（50–20,000） |

- 由后台 Blender 的固定脚本完成，通常一两秒。由多个相互穿插的部件组成的模型也会被填成实心。
- 每个面从一张很小的调色板贴图里取一种颜色，所以在 Godot、Unity 和 OBJ 里颜色都能正常显示。
- 风格化版本可以直接导出；来源版本有骨架时可以再绑定动画；要局部重绘时先「优化」一次，烘焙成常规贴图。
- 风格化会改变轮廓，蓝图评分通常会下降，这是正常的。

## 导出与资源中心

- 在「导出」中先采用一个版本，再选择引擎预设和文件格式，然后导出资产包：

  | 预设   | 格式                                 | 内容                                                                         |
  | ------ | ------------------------------------ | ---------------------------------------------------------------------------- |
  | 通用   | GLB（默认）、FBX、OBJ+MTL、USDZ、STL | GLB 时另附 `lod1.glb`、`lod2.glb`、`collision.glb`                           |
  | Godot  | GLB                                  | 碰撞体按 Godot 导入规则命名，导入后自动生成静态碰撞体；LOD 由 Godot 自己生成 |
  | Unity  | FBX                                  | Y 轴向上、米制；LOD 命名为 `_LOD0`、`_LOD1`…，碰撞体为 `_Collider`           |
  | Unreal | FBX                                  | 由 Unreal 导入器换算为 Z 轴向上和厘米；LOD 命名为 `_LOD0`…，碰撞体为 `UCX_`  |

- FBX 和 OBJ 的贴图放在 `textures/` 目录；GLB 和 USDZ 内嵌贴图。STL 用于 3D 打印，导出时会在 `validation.json` 里记录网格是否闭合。
- 资产包还包含缩略图、3/4 渲染图、源码（优化版本导出其原始版本的源码）、有骨架时的 `skeleton.json`、`asset.json` 和含蓝图评分的 `validation.json`。清单会如实写明 UV、贴图、LOD 和碰撞体是否提供。
- 除了通用 GLB，其他格式都由后台 Blender 转换，需要本机装有 Blender。
- 超出三角面预算时，需要勾选确认后才能导出。
- 「保存到资源中心」会复制已采用的 GLB，并记录它来自哪个 3D 生成工程和版本。

## 保存与恢复

- 工程保存在系统 Documents 目录下的 `Aha/Gen3D/<projectId>/`：
  - `project.json`：工程清单
  - `references/`：参考图
  - `blueprint/`：三视图剪影
  - `versions/`：不可变的版本，包括模型、渲染图、剪影、差异图和评分；Blender 版本还有 `model.blend` 和运行日志，有骨架的版本有 `skeleton.json`，优化版本有 `process.json`、LOD 和碰撞体 GLB
  - `jobs/`：尚未发布的任务
- 构建失败时保留上一个可用版本和错误信息，可以「重试构建」。
- 重启后，执行中的任务会标为中断，迭代授权也会结束。
- 删除会话只解除绑定，模型和参考图都会保留。

构建需要 Aha 桌面版。纯网页环境下只能查看已保存的模型和比对结果。
