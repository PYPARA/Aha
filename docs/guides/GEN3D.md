# 3D 生成

3D 生成在主导航的 3D 工坊之后。它从一张三视图参考出发：AI 用 Three.js 和 SDF（有向距离场）或 Blender 建模，每次构建都和参考剪影比对评分，再根据差异图修改，直到轮廓吻合。每一轮结果都保留为候选版本。

## 参考与蓝图

1. 新建 3D 资产，打开工程。
2. 在「参考与蓝图」中添加参考图：
   - 「上传参考图」：一张纯色背景、从左到右依次排列正视、侧视、背视的图片。
   - 「生成三视图」：用你的绘图渠道生成一张 1536×1024 的三视图。生成前会显示渠道和模型，结果会记录在绘图中，渠道可能计费。
3. 填写资产的真实高度（米），点击「提取蓝图」。Aha 按列切出三个视图，提取剪影，三个视图共用同一个比例。
4. 检查三个剪影，无误后点击「确定」。

侧视图里的物体正面朝左或朝右都可以，评分会自动匹配镜像方向。

## 建模路线与骨架

AI 助手每次构建时自己选择路线，「属性」面板会显示两条路线当前是否可用，版本信息里会标出每一版用的路线。

- **Three.js + SDF**：默认路线，构建只要几秒，适合大多数资产。
- **Blender**：AI 写 Blender Python，可以用 Skin、细分、倒角、布尔、镜像等修改器。
  - 需要先在 3D 工坊里设置好 Blender 运行环境。3D 生成和工坊共用这套环境，同一时间只运行一个 Blender 任务；工坊正在用 Blender 时，3D 生成最多等待 90 秒。
  - 每次构建都会启动一个专用 Blender 窗口，比 Three.js 路线慢。
  - 运行环境没准备好时，AI 的 Blender 构建会被直接拒绝，不消耗授权轮数。
- **骨架**：做角色、生物、树木这类资产时，AI 会先给出骨架（关节位置、父子关系和半径），再沿骨架生成身体，两条路线都支持。骨架随版本保存，导出时一起导出，供以后绑定骨骼使用。当前版本还不做骨骼绑定。

## 生成与迭代

- 「属性」里可以填写资产描述和三角面预算。
- 设置「最多轮数」（1–10），点击「开始生成」：
  - Aha 会授权 AI 助手在这么多轮内自行构建，并在「AI 助手」中预填一条消息，由你发送后开始。
  - 只消耗会话模型轮次，不调用生图。
  - 最大偏差区域低于 2%，或分数连续两轮提高不足 1 分时自动停止。
  - 重启后不会自动继续。
- 没有授权时，你每发一条消息，AI 最多构建一次。
- 迭代过程中可以随时在任务栏或属性面板停止。

每轮 AI 会读取蓝图、上一版的差异图和渲染图，然后只修改有偏差的部分。模型思考一轮通常需要几分钟，构建和评分只要几秒。

## 查看与比对

- 「模型」视图复用 3D 工坊的查看器，可以旋转、平移、缩放，切换材质、纯色、线框、网格和包围盒。
- 「比对」视图显示三视图差异图：灰色表示吻合，橙色表示模型多出，蓝色表示模型缺少。同时列出偏差最大的区域和各视图 IoU。
- 版本列表显示每一版的轮次、分数和最大偏差。查看其他版本不会自动采用它。

评分只反映剪影和比例，风格与细节请在模型视图中检查。底部信息栏会提示非流形边等需要处理的问题。

## 优化与烘焙

AI 建出的模型通常面数很高、没有 UV。「优化」工具会从当前查看的版本生成一个游戏可用的新版本：

1. 选择目标面数：主资产 2 万、普通道具 5 千、背景 1.5 千、手机 800，或者自定义（100–200,000）。
2. 选择贴图尺寸（512–4096），以及要做的处理：
   - 修复网格：焊接重复顶点、删除游离的点和边、重算法线。
   - 重新展开 UV 并烘焙贴图：把原模型的颜色、粗糙度、金属度、法线和 AO 烘焙到低模上，输出一张颜色图、一张法线图和一张 AO/粗糙度/金属度合并图。不勾选时保留原有材质和 UV。
   - 颜色来源（勾选烘焙时）：
     - 模型材质：沿用模型原有的颜色。
     - 投影三视图参考：按蓝图对齐把参考图画到模型可见的表面上。被挡住的地方（比如面罩后面、身体被尾巴挡住的部分）不会被错误上色，顶面、底面和投不到的地方保留材质颜色。需要已确认的蓝图，以及按这份蓝图评过分的版本；蓝图重新提取后，要先重新构建一个版本。
   - 材质预设（勾选烘焙时）：可以给每个材质选一种程序材质——木头、拉丝金属、喷漆金属（边缘磨损）、金、石头、布料、皮革、塑料。预设会加上纹理、凹凸和粗糙度变化，然后烘焙进贴图。和投影一起用时，颜色以投影为准，预设提供凹凸、粗糙度和金属度。
   - LOD：再生成 50% 和 25% 两级，共用同一套贴图。
   - 碰撞体：包围盒或凸包（最多约 250 面）。
3. 点击「生成优化版本」。

优化在后台 Blender 里运行 Aha 自带的固定脚本，不执行 AI 代码，也不消耗模型轮次，通常 5–10 秒，投影和材质预设各会多几秒；4096 贴图会更慢，可以随时取消。需要本机装有 Blender（在 3D 工坊里设置路径即可，不需要准备 MCP 运行环境）。优化结果是一个新的候选版本，同样会按蓝图评分、渲染和检查，版本信息里显示面数变化、LOD 和碰撞体。AI 助手继续建模时会基于它的原始版本，不会修改优化版本。

工作台的渲染图没有环境反射，金属度高的材质在里面会显得偏暗；在游戏引擎或 Blender 里有环境光时显示正常。

## 导出与资源中心

- 在「导出」中先采用一个版本，再选择引擎预设和文件格式，然后导出资产包：

  | 预设   | 格式                                 | 内容                                                                         |
  | ------ | ------------------------------------ | ---------------------------------------------------------------------------- |
  | 通用   | GLB（默认）、FBX、OBJ+MTL、USDZ、STL | GLB 时另附 `lod1.glb`、`lod2.glb`、`collision.glb`                           |
  | Godot  | GLB                                  | 碰撞体按 Godot 导入规则命名，导入后自动生成静态碰撞体；LOD 由 Godot 自己生成 |
  | Unity  | FBX                                  | Y 轴向上、米制；LOD 命名为 `_LOD0`、`_LOD1`…，碰撞体为 `_Collider`           |
  | Unreal | FBX                                  | 由 Unreal 导入器换算为 Z 轴向上和厘米；LOD 命名为 `_LOD0`…，碰撞体为 `UCX_`  |

- FBX 和 OBJ 的贴图放在 `textures/` 目录；GLB 和 USDZ 内嵌贴图。STL 用于 3D 打印，导出时会在 `validation.json` 里记录网格是否闭合。
- 资产包还包含缩略图、3/4 渲染图、源码（优化版本导出其原始版本的源码）、有骨架时的 `skeleton.json`、`asset.json` 和含蓝图评分的 `validation.json`。清单会如实写明 UV、贴图、LOD 和碰撞体是否提供。
- 除了通用 GLB，其他格式都由后台 Blender 转换，需要本机装有 Blender。
- 超出三角面预算时，需要勾选确认后才能导出。
- 「保存到资源中心」会复制已采用的 GLB，并记录它来自哪个 3D 生成工程和版本。

## 保存与恢复

- 工程保存在系统 Documents 目录下的 `Aha/Gen3D/<projectId>/`：
  - `project.json`：工程清单
  - `references/`：参考图
  - `blueprint/`：三视图剪影
  - `versions/`：不可变的版本，包括模型、渲染图、剪影、差异图和评分；Blender 版本还有 `model.blend` 和运行日志，有骨架的版本有 `skeleton.json`，优化版本有 `process.json`、LOD 和碰撞体 GLB
  - `jobs/`：尚未发布的任务
- 构建失败时保留上一个可用版本和错误信息，可以「重试构建」。
- 重启后，执行中的任务会标为中断，迭代授权也会结束。
- 删除会话只解除绑定，模型和参考图都会保留。

构建需要 Aha 桌面版。纯网页环境下只能查看已保存的模型和比对结果。
