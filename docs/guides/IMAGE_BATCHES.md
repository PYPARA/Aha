# 批量生图

批量生图位于最左侧主导航，默认在绘图之后。它把需求、对话与资料整理成可审阅的任务清单，统一生成、挑选和保存结果。入口继续支持现有排序、隐藏与激活规则。

## 完整流程

1. 新建批次，在「批次设置」填写需求概要和默认生图渠道、模型及参数；需要整批风格统一时填写「批次风格」。生成前无需配置资源库。
2. 在「需求与资料」开始批次对话，使用现有聊天模型并添加文档或参考图。每个批次独立绑定会话；首次打开工作台不会创建或发送会话。
3. AI 提交的任务方案出现在「待应用变更」（「需求与资料」和「任务清单」顶部都会显示）。点击「预览修改」逐项核对名称、输出路径、提示词、张数、尺寸、质量、背景、模型和参考图的变化，以及批次风格、默认参数的变化和预计图片数，然后选择「应用并检查生成」直接进入第 5 步的确认，或「仅应用」只更新草稿。两者都不会提交生图。提交失败时 AI 会收到具体原因并重新提交。
4. 在「任务清单」逐项检查。每行显示最近一次生成状态、已采用或最新结果的缩略图、提示词首行和规格（输出路径、尺寸、张数、质量、背景；模型与默认不同时才显示）。行右侧的开关控制启用，「···」菜单提供编辑、查看结果、重新生成、补齐缺失、复制、上移/下移和移除。点缩略图或「查看结果」在右侧抽屉中查看该任务的全部候选，可直接采用、作为参考图、重新生成或编辑任务，不离开任务清单。用「设置参数」批量修改所选任务的张数、尺寸、质量、格式或背景（只改动过的项会应用）。任务填写了输出路径时按首级目录分组并显示进度，可折叠、整组选择；也可按启用状态筛选或搜索名称和路径，选择只作用于当前显示的任务。顶部计数显示全部任务数和已启用数。手工编辑保存到草稿。
5. 底部操作栏显示本次将生成的任务数和图片数。点击「检查并生成」，核对本次任务数、图片数、渠道和按目录分组的逐项规格，再「确认生成」。可在「本次使用的渠道与模型」中切换渠道和模型：只影响同时跟随批次渠道与模型的任务，单独设置了渠道或模型的任务不变，批次设置也不改变。已启用任务中若有已经生成过的，会提示并可一键「停用这些任务」后重新检查。没有可靠费用依据时显示未知。执行中底部栏显示进度和暂停/继续/取消剩余，「生成记录」在侧边抽屉中查看历次尝试并批量补齐或重新生成。
6. 在「生成结果」按输出目录、任务顺序查看候选，可按结果状态、输出目录筛选并搜索任务名或文件名；卡片显示交付文件名，实际尺寸与请求不同时会提示「请求尺寸」。不满意的结果点卡片上的「重新生成」（多选时「重新生成所选任务」）：只生成对应任务，并使用任务**当前**的提示词和参数，需要调整时先编辑任务；停用的任务也可以这样单独生成。可预览、对比、导出，复制到绘图继续修改，或「用于精灵」送入精灵项目作为素材。
7. 选中需要保留的候选，点击「加入资源中心」，明确选择资源库中的目录或主动创建目录。任务有输出路径时，会在所选目录下按路径创建子目录（见「输出路径与交付命名」）。原始结果始终保留在所属批次。

「标记采用」与「加入资源中心」独立：标记不会复制文件，入库也不自动改变采用状态。结果详情和资源详情提供来源回跳。

## 批次风格

「批次设置 → 批次风格」包含风格描述（最多 4000 字）和最多 8 张风格参考图，也可以在资源中心选择图片「用于批量」直接加入风格参考图。确认生成时，风格描述放在每个任务提示词之前（中间空一行），风格参考图排在任务参考图之前，同一张图只发送一次；确认对话框展示实际发送的提示词和参考图数。合并后单个任务最多 16 张参考图、80 MiB，超出时在检查中指出对应任务。

风格在确认时冻结进每次尝试。之后修改风格只影响下一次确认；补齐和重新生成沿用原尝试的风格，不会叠加或换成新风格。

AI 方案也可以设置批次风格（风格描述、风格参考图）和默认参数，预览中单独列出变更前后；渠道和模型仍由你选择。需求里每条提示词共用的前缀应放进风格描述，而不是复制到每个任务。

## 分阶段参考

本批已生成的结果可以作为后续任务的参考图，用于「先定样张、再统一风格」的流程：

1. 先只启用样张任务（例如一张角色立绘、一张图标），生成后在结果卡片上点「标记采用」。
2. 采用后，结果页顶部会询问是否把它设为**同一输出目录**其余任务的参考图（例如 `heroes/` 其余 7 项），「设为参考并启用」一步完成；其他目录不受影响，样张所在任务同时停用，避免下次再生成一遍。
3. 需要精确控制时点卡片上的「作为参考图」，选择参考范围：
   - **仅所选任务**：按目录分组、可搜索，逐项或整组勾选，例如只给 `portraits/ember.png` 加焰的立绘。
   - **批次风格（所有任务）**：加入批次风格参考图，确认生成时放在每项任务自身参考图之前，之后新增的任务也会使用。

   对话框默认勾选「停用样张所在的任务」。

4. 也可以在任务编辑器的「从本批结果选择」里挑选，或直接让 AI 按名称对应设置（AI 能读取结果）。然后再次「检查并生成」。

默认只作用于所选任务；只有明确选择「批次风格」才会影响全部任务。任务之间没有自动依赖，样张满意后由你决定何时加入后续任务。只有本批的结果能这样引用，其他批次的结果会被拒绝。

## 输出路径与交付命名

任务可填写「输出路径」，即相对资源中心目标目录的路径，如 `heroes/ember.png`。路径不能以 `/` 开头，也不能包含空段、`.` 或 `..`。路径在确认生成时冻结进尝试与结果。

加入资源中心时，会在所选目录下逐级创建并索引子目录；同一任务里已采用的候选使用原文件名，其余候选依次加 `-2`、`-3`；没有已采用候选时全部编号（`-1` 起）。扩展名以实际图片格式为准，目标已有同名文件时自动避让。导出选中时使用同样的文件名，但浏览器下载不创建目录。没有输出路径的任务沿用「任务名*尝试号*序号」的命名。

## 对话与资料

附件接收沿用普通聊天的图片/文件逻辑和容量校验，不按扩展名设置批次入口白名单。实际能否读取内容取决于当前聊天模型及其工具。上传成功表示附件已接收，不表示 AI 已读取或解析。

已发送、纳入批次的资料保存独立快照。资料区显示名称、大小、AI 报告的读取情况和失败原因；AI 方案也会列出未读取资料、假设和待确认事项。参考图片进入现有图像资产存储，建立批次引用。删除关联会话不会删除这些快照或生成结果。

普通会话顶栏的「整理为生图批次」让你明确选择带入的文本与附件，然后创建独立批次会话并保留来源链接。跨会话附件由服务端检查原消息归属后复制，不直接沿用原附件身份；复制失败可重试。

对话中的“开始生成”会引导你检查清单并在工作台确认。AI 工具可以读取上下文、报告资料读取情况、提交方案和预览结果，不能直接应用方案或提交生图。

## 草稿、执行与恢复

任务继承批次默认配置，也可设置行级覆盖。每次确认会保存独立、完整的冻结执行：启用任务、提示词、渠道与模型、参数、参考图片及资料引用。执行期间仍可准备下一版草稿，已排队与已提交的执行保持原样；同一批次只能有一次活跃执行。

草稿有版本号。其他窗口或操作修改了版本时，旧编辑不会覆盖新数据。任务编辑器会保留本地修改；「重新读取基线，保留我的编辑」读取最新清单，如果同一任务也发生变化，需要明确确认覆盖该任务。其他任务保留最新版本。

| 操作或状态   | 行为                                                                          |
| ------------ | ----------------------------------------------------------------------------- |
| 暂停         | 阻止尚未发送的请求，已发送请求继续返回并保存                                  |
| 继续         | 恢复派发；认证、额度或限流问题需先处理渠道，再继续                            |
| 取消剩余     | 取消未开始项；已发送项尽力取消，可能已执行或计费；已返回结果保留              |
| 补齐缺失图片 | 明确选择尝试记录，核对范围后只生成缺失数量；已保存的补齐候选会计入缺口        |
| 重新生成     | 明确选择尝试记录，核对范围后创建新尝试；原候选保留                            |
| 待核实       | 请求已发送但结果不明，不自动重发。查看请求记录或上游请求 ID，核实后再决定重试 |
| 保存中断     | 尝试恢复已落盘的原始响应与保存清单；补保存不调用图像模型                      |

任务结束数、成功保存图片数和问题项数分别显示。成功图片计数以原图可靠保存为准，相同图片内容也会保留独立候选身份。

批量与直接绘图共用渠道额度。批量默认最多占用每渠道两个并发；渠道额度至少为二时，为交互请求保留一个机会。单并发渠道在当前请求结束后优先处理直接绘图，再继续轮转批次。

切换页面和收起窗口可以继续运行。彻底退出会提示活跃批次和正在入库的操作；重启恢复未发送任务与可恢复的保存阶段，状态不明的已发送请求进入待核实。功能不承诺休眠、离线或远程无人值守执行。

## 结果与手动入库

结果按任务组织，显示尝试与时间。单击单选，Cmd/Ctrl 加选，Shift 范围选择，也可打开显式多选；左右方向键、Home/End 可移动选择，Cmd/Ctrl+A 选择当前已加载项，空格预览，Escape 关闭并恢复焦点。预览不会清除筛选、选择和浏览位置。缩略图按需加载，结果分页读取，原图只在预览或导出时加载。

资源复制由应用级控制器执行，与批次页面挂载无关。操作 ID、结果清单、目标库和目标目录身份、逐项回执保存在桌面端。换页、重载或重启后可恢复；失败项单独重试，已提交文件通过结果来源恢复关联，同一结果在同一库内重复加入返回已有资源。不同结果即使字节相同，也保留独立来源。

入库失败不会改变生成状态或再次调用模型。资源库不可写或索引失败时，先在资源中心重扫恢复；目标库或目录失效时重新选择位置，不会自动切换目录。资源移动、重命名按稳定 ID 回跳；已移入废纸篓的资源显示不可用，不自动重新入库，批次原图仍保留。

## 绘图与生命周期

绘图默认显示直接绘图及无法可靠分类的旧记录；「全部来源记录」可查看所有来源。批量和精灵的过程主要在所属工作台管理。旧精灵记录只根据可核实的工程引用补充来源，不按提示词猜测。

归档可恢复。移除批次记录默认保留原图与已入库文件；移除后当前页面提供独立的「清理批次原图」。清理需再次明确确认，移除批次结果和资料快照，已入库文件和其他仍在引用的资产保留。无法完整枚举引用时停止清理。

每批任务数不设上限；启用任务合计最多 **500 张计划图片**，分阶段的后续任务可先停用。单任务张数、参考图和参数沿用现有生图限制。当前范围不包括定时执行、变量组合、多模型对比、远程无人值守和统一资产存储。

开发约束、数据位置与回归入口见[创作功能维护](../development/CREATIVE_WORKBENCHES.md)。
