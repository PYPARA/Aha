# 3D 工坊

3D 工坊在主导航的精灵动画与资源中心之间。每个工程用于一个静态游戏道具，可包含多个命名部件。通过 Aha 当前会话模型生成 Three.js 建模源码或 Blender Python，构建真实 GLB 后预览、调整、采用和导出。

## 创建与建模

1. 新建 3D 工程，选择 Three.js 或 Blender MCP。
2. 点击“开始建模对话”，使用普通聊天的模型选择、附件和历史。描述道具的形状、尺寸、部件、风格及面数要求。
3. AI 读取当前工程，通过 `model3d` 工具提交新候选。任务区显示构建、校验、失败或取消状态。
4. 继续用自然语言修改。普通迭代直接构建新候选；采用与导出由工作台操作。

Three.js 随应用离线打包，适合低多边形道具、曲线和参数化几何。Blender 适合进一步编辑、UV 和可转换为标准 PBR 的材质。Three.js 版本可作为 Blender 编辑的父版本；Blender 编辑后的网格不会自动变回参数化 Three.js 源码。

本地构建需要桌面宿主。缺少宿主时，界面明确提示本地执行不可用。首版不提供角色绑定、动画、AI 贴图、云端 3D 服务、LOD、碰撞体或 Unity/Unreal 专属资产包。

## Blender 运行环境

运行环境设置检测 Blender 与 uvx，可填写或选择可执行文件。macOS 通常为 `/Applications/Blender.app/Contents/MacOS/Blender` 和用户目录下的 `.local/bin/uvx`。准备运行环境后可保存并检查 MCP 连接。

依赖固定为 `mcp-for-blender==2.2.2`，安装在 Aha 私有运行目录。Aha 启动可见的专用 Blender 图形窗口，使用独立用户配置、启动脚本、本机端口和工程标识，不修改其他 AI 客户端与 Blender 全局配置。上游插件不支持用 `blender -b` 提供 MCP 服务。

启用上游安全模式并关闭遥测、第三方资产服务。专用实例用于工程隔离，不是操作系统级 Python 沙箱。Aha 仅终止自己启动的子进程；全局同时执行一个 Blender 建模任务。连接错误、崩溃与超时保留任务源码、日志及已有检查点，失败的操作不自动重放。

## 检查、版本与材质

中央查看器支持旋转、平移、缩放、重置视角、材质/实体/线框、网格、包围盒和部件选择。键盘 R 重置视角，方向键平移。显示模式只改变查看器；正式材质和 GLB 不变。离开查看器或切换模型会释放 GPU 资源，后台停止绘制。

对象、版本和当前预览分别管理。查看其他版本不会采用它；AI 下一轮从当前预览版本读取上下文。新结果成为候选，只有“采用此版本”更新正式导出版本。可以重新采用历史版本回退。

属性面板提供工程名称、三角面和贴图预算、Three.js 可编辑参数，以及 PBR 材质的颜色、粗糙度、金属度、不透明度。参数或材质修改生成新候选，旧版本保留。源码可以查看、复制或保存，不提供完整代码编辑器。

Base Color、Normal、Roughness、Metalness 接收本地 PNG/JPEG。导入时复制到工程并规范为 PNG，最大 4096×4096、32 MiB；导出时嵌入贴图并按 glTF 规则处理色彩空间及金属度/粗糙度通道。缺少 UV 会明确提示。Blender 非标准 PBR 节点会报出不能转换的节点类型，修正后再构建。

默认单位为米，Y 轴向上，生成模型的轴心位于底部中心；默认建议预算为 5000 三角面、2K 贴图。检查统计来自真实模型。Three.js 单次源码执行最多 30 秒、源码 1 MiB，模型最多 100 MiB、100 万三角面和 5000 个部件。预算可改，固定容量上限不可改。

## 导入、导出与资源中心

导入支持 GLB，以及与 `.bin`、PNG/JPEG 依赖放在同一目录范围内的 glTF。拒绝远程 URL、绝对资源路径、逃逸路径和缺失资源；总包容量上限 100 MiB。模型导入不会执行外部源码，动画与绑定模型暂不支持。

导出仅使用明确采用的版本，与该版本预览读取同一份 GLB。导出前重新校验文件哈希和 glTF 完整性。损坏模型阻断；超出建议预算时需要勾选仍然导出。

通用和 Godot 预设均输出标准 `model.glb`，同时提供 `thumbnail.png`、`asset.json` 和 `validation.json`。可附带建模源码、参数和父版本源码记录、使用的本地贴图及 `.blend`。资产清单明确标记 LOD 与碰撞体未提供。目标目录中新建带版本和独立后缀的子目录，完成临时写入后原子提交。

“保存到资源中心”使用已采用 GLB 和原有目标目录选择、持久化入库回执及失败重试。来源记录工程与版本，详情可返回 3D 工程；列表使用图标，只有详情打开时加载共享查看器。入库失败重试只复制已有产物，不重新调用 AI。

## 保存与恢复

工程默认在系统 Documents 目录下的 `Aha/Models3D/<projectId>/`，跟随 Aha 现有 Documents 配置。`project.json` 是工程清单，`versions/` 保留不可变版本，`jobs/` 保留未发布任务，`textures/` 保留本地贴图。

每次任务先保存输入，再执行并校验 GLB，全部成功后发布新版本。失败保留上一可用版本与错误。重启时，已提交结果按哈希恢复；执行状态不明的任务标为已中断，需要显式重试。删除会话只解除绑定，归档工程保留所有模型、版本与源文件。
